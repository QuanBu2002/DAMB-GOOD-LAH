# DAMB GOOD LAH — Wok-First Host Search — 2026-09-07

## Search reset

Elements is deprioritized. It is too polished / destination-oriented for the host-kitchen archetype DAMB GOOD LAH wants.

The search should favor **small practical Asian operators with native or near-native high-heat stir-fry capability**, especially Chinese, Thai, Korean and Southeast Asian restaurants in San Jose / Santa Clara / Campbell / Milpitas. The target is not prestige; it is underused weekday kitchen capacity, real hot-line capability, operator flexibility, and low fixed cost.

## Governing search rule

Prioritize in this order:
1. Native wok capability / heat recovery
2. Monday-Friday daytime availability
3. Small independent / owner-operated profile
4. Willingness to execute County rental-kitchen paperwork
5. Dedicated storage
6. Fryer / range / prep / packing compatibility
7. Fixed monthly economics

Four reliable weekdays is sufficient. Three weekdays can still be an excellent pilot. One- or two-day true-wok kitchens remain on the board as redundancy and equipment benchmarks.

Public dining hours do not prove the kitchen is idle. Actual prep arrival and catering production must be confirmed directly.

## New category breakthrough — dinner-only Korean BBQ / pocha kitchens

The strongest new search lane is **casual Korean BBQ / late-night pocha restaurants**. Several open only around 5-5:30 PM yet produce fried rice, stir-fries, fried chicken, pancakes and hot-pot dishes. They may not have a Chinese-style wok bank, so the exact burner/wok configuration must be physically verified, but their weekday schedule and practical operator profile are unusually strong.

- a hooded high-output gas position that can safely run our approved wok burner?
