# DAMB GOOD LAH — Recipe Universe Prototype Ranges v0.1

## Status

**R&D starting ranges only — not frozen recipes.**

These ranges are deliberately broad. They translate the recipe-universe architecture into something testable without pretending we already know the final formula. All processed ingredients remain subject to HALAL-SKU approval.

The purpose of this file is to reduce random experimentation: every first test should start inside a historically/culinarily plausible range, then move based on sensory data, yield, delivery performance and cost.

---

# 1. Neutral dried-chile mother

## Goal
One mechanical prep that can branch into Padang, sambal, Mee Goreng and CKT without sharing the finished sauce.

### Starting method
- dried red chile, stemmed
- soak until fully softened
- drain
- blend with only enough clean soaking water / fresh water to move smoothly
- no sugar
- no acid
- no salt
- no belacan
- no soy

### Target output
A thick, spoonable chile puree that can be weighed consistently.

Record:
- dry chile weight
- soaked/drained weight
- added water
- final puree weight
- puree yield per kg dry chile

This is **MP-01** and should become a measured production standard before final sauce work.

# 2. Padang rempah — starting aromatic balance

External rendang/Padang-style references consistently cluster around shallot/onion, garlic, ginger, galangal, lemongrass, chile, turmeric, coriander/fennel/cumin-family spices and coconut, with the paste cooked until aromatic/oil-separated before prolonged coconut cooking.

### Aromatic solids — starting percentage ranges by weight

| Component | Start range |
|---|---:|
| shallot / red onion | 28–35% |
| lemongrass, tender portion | 12–18% |
| neutral dried-chile mother | 12–18% |
| garlic | 6–9% |
| ginger | 5–8% |
| galangal | 5–8% |
| fresh turmeric | 2–4% |
| toasted ground coriander/fennel/cumin blend | 4–7% |
| toasted coconut / kerisik component | 5–10% |

Oil/water for grinding are process variables, not part of the aromatic percentage table.

### Wave-1 test
Make three 1 kg rempah-aromatic variants:
- **P-A:** shallot-forward / moderate chile
- **P-B:** balanced midpoint
- **P-C:** lemongrass/galangal-forward

Then cook each with the same coconut-milk and salt/sugar/acid framework.

Do not optimize chicken and beef separately yet. First find the best mother curry.

# 3. Padang mother-curry concentration tree

Once the mother curry is chosen, branch by **reduction and finishing**, not by making three unrelated sauces.

## Branch A — Rice curry
Target:
- spoonable
- glossy
- clings to protein/rice
- enough free sauce to mix with rice

## Branch B — Dry Curry Mee
Target:
- 20–35% less free water than Rice Curry branch
- coats yellow noodles without pooling
- aroma remains Padang rather than becoming generic curry noodles

## Branch C — Roti dip
Target:
- slightly looser than noodle branch
- stronger salt/acid may be needed because roti dilutes perception
- should remain recognizably the same Padang mother

### Mandatory test
Blind taste all three against a fully independent curry made specifically for each dish. If the mother/branch system is weaker, abandon the efficiency assumption.

# 4. House sambal — starting balance

A nasi-lemak-style sambal should be its own cooked chile/aromatic lane rather than neutral chile paste with sugar added at service.

### Starting cooked-sambal solids/flavor balance

| Component | Start range |
|---|---:|
| neutral dried-chile mother | 35–45% |
| shallot/onion | 25–35% |
| garlic | 4–7% |
| certifier-approved belacan / shrimp-paste component | 2–5% |
| tamarind concentrate | 5–8% |
| palm/brown sugar equivalent | 8–12% |
| salt | sensory-controlled |

Oil is a cooking medium and should be measured separately.

### Branch logic

#### Nasi Lemak sambal
Keep balanced and rounded; compatible with coconut rice, egg and ikan bilis-peanut crunch.

#### Future Sambal Shrimp
Finish with prawn oil / prawn concentrate only if RU-10/RU-11 prove a sensory gain.

#### Future Sambal Shrimp Mee
Same sambal family, but allow charred-lime finish and noodle-specific salt/acid adjustment.

# 5. Mamak Mee Goreng sauce — starting blend

### Starting finished sauce by weight

| Component | Start range |
|---|---:|

| ketchup / tomato sauce | 20–28% |
| dark/caramel soy | 10–15% |
| cooked chile component | 15–22% |
| tamarind concentrate | 4–8% |
| water / stock equivalent | 5–10% |

### Test variants
- **MG-A:** sweeter / darker
- **MG-B:** midpoint

Lock sauce only after testing with the full noodle build including potato, tofu, egg and sprouts.

# 6. CKT seasoning — starting blend

CKT references consistently separate a soy-forward seasoning from the actual high-heat wok process. The sauce must be concentrated enough that the wok is not cooled by excess liquid.

### Starting seasoning by weight

| Component | Start range |
|---|---:|
| light soy | 42–50% |
| dark soy | 14–20% |
| certifier-approved oyster-style sauce | 18–25% |
| fish sauce, if approved/desired | 2–5% |
| sugar | 4–7% |
| white pepper | 0.3–0.8% |
| water only if needed for dosing | 0–8% |

### Separate CKT chile
Never pre-mix all heat into the seasoning. Keep chile as its own dose so spice can vary without changing salinity/sweetness.

### Service target
The entire seasoning dose for one portion should be small enough to flash/caramelize on the wok rather than steam the noodles.

# 7. CKT chile paste — starting architecture

### Aromatic solids

| Component | Start range |
|---|---:|
| neutral dried-chile mother | 55–70% |
| shallot | 15–25% |
| garlic | 8–12% |
| optional approved belacan | 0–4% |
| salt/sugar | minimal, because main seasoning controls balance |

Cook until raw aromatics are gone and oil separates; the final paste should be concentrated and wok-friendly.

This remains a protected CKT component even though it shares upstream dried chile and shallot prep.

# 9. Chicken base-prep experiment

The core chicken prep must remain intentionally neutral enough to branch, but flavorful enough that it is not generic boiled meat.

### Test design
Prepare one chicken batch with:
- salt
- restrained aromatics compatible with all three dishes
- no finished Padang curry
- no finished sambal
- no sweet soy

Then branch:

## Chicken Rice
Finish with Padang curry + chicken-skin crisp.

## Nasi Lemak
Finish with Nasi-Lemak-specific treatment + sambal on plate.

## Curry Mee
Finish directly in reduced Padang curry/noodle build.

### Kill rule
If tasters describe the three proteins as “the same chicken with different sauce,” the base is too finished or the branches are too weak.

# 10. Potato two-output experiment

Start from one par-cooked potato batch.

### Output A
Mee Goreng potato body:
- tender enough to absorb sauce
- survives wok toss

### Output B
Crispy potato:
- chill/dry a measured portion
- fry/roast/crisp
- use as finish

Record whether one doneness point can support both. If not, share raw SKU and initial prep only.

---

# 11. Tofu two-output experiment

One firm tofu SKU.

### Output A
Mee Goreng tofu:
- tender interior
- enough surface structure for wok

### Output B
Curry tofu crisp:
- pressed/dried further
- crisped in advance if hold test passes
- finished with a controlled Padang/curry seasoning

Again: share the SKU and upstream work, not necessarily identical final cooking.

# 12. Shrimp shell R&D trigger

Do not activate because it sounds clever.

Activate only when:
- shell-on price is low enough to beat P&D after measured edible yield;
- prep labor is available without lowering throughput;
- shell stream can be processed immediately and safely;
- prawn oil/stock produces a measurable sensory lift.

### First shell experiment when activated
1000 g shell/tail trim → measure:
- oil infusion yield
- stock yield
- reduced concentrate yield
- hands-on minutes
- passive minutes
- freezer/refrigerator burden

Blind-test against identical CKT and shrimp sambal without shell-derived flavor.

# 13. Source notes

Reviewed as structural reference, not copied formulas:

- SBS Food beef rendang references: recurring use of shallot/onion, garlic, ginger, galangal, lemongrass, chile, coriander/fennel/cumin-family spices, coconut milk, toasted coconut and prolonged reduction.
- Asian Inspirations Mamak Mee Goreng: dedicated sauce built around caramel soy, kecap manis and ketchup plus a separate dried-chile/tamarind paste; yellow noodles, tofu, potato, egg and sprouts.
- Malaysian CKT references including RecipeTin Eats, Singapore Food Agency and Southeast Asian Table: fresh flat rice noodles, prawns, egg, sprouts, chives, high heat, separate soy seasoning and chile.
- Rasa Malaysia nasi lemak: sambal cooked from chile/aromatic paste with tamarind, sugar and ikan bilis context.
