# Highest-leverage preps

## Tier A — unlock 3+ launch dishes

### 1. Chicken base prep
Unlocks three launch mains.

### 2. Padang curry mother
Unlocks four commercial formats:
- Chicken Rice
- Beef Rice
- Curry Mee
- Roti dip

### 3. Aromatic mise
Feeds effectively the entire menu.

### 4. Neutral dried-chile puree
Potential upstream input for all four flavor lanes without making the finished sauces identical.

### 5. Bean sprouts
One fresh SKU across all three noodle mains.

### 6. Coconut milk inventory
Feeds Padang + Nasi Lemak.

# High-value two-output transformations

## Chicken skin
Input → crisp + rendered chicken fat.

## Beef trim
Input → braise + rendered fat → beef-fat shallot crisp.

## Potato
Input → Mee Goreng body + crispy garnish.

## Tofu
Input → tender Mee Goreng component + Curry Mee crisp.

## Shrimp shell stream
Input → meat + optional prawn oil + optional concentrated stock.
Activate only when shell-on economics support it.

# Bottleneck dependencies

These ingredients/preps can block only one dish but that dish cannot launch without them.

## CKT
- halal chicken lap cheong
- fresh flat rice noodles
- garlic chives
- dedicated seasoning
- dedicated chile
- high-output wok

Because CKT has more single-dish dependencies than any other main, it remains the highest operational fragility dish even when food cost is acceptable.

## Nasi Lemak
- ikan bilis-peanut crunch
- coconut rice

Peanut allergen controls should remain intentionally localized.

# Prep concentration metric

For every production prep, track:

`leverage = number of sellable dishes served / paid prep minutes`

High leverage is good only if flavor identity remains intact.

Example:
- 30 minutes peeling/processing aromatics that support six dishes = excellent.
- 30 minutes making a garnish used on one low-volume dish = must create disproportionate sensory value.

---

# SKU reduction targets

Aim for:
- one main chicken SKU
- one primary braising beef SKU
- one primary shrimp size/spec
- one yellow noodle SKU
- one separate fresh flat rice noodle SKU
- one firm tofu SKU
- one potato SKU
- one egg SKU
- one bean-sprout SKU
- one primary coconut-milk SKU at each volume stage
- one neutral frying oil

Protected specialty SKUs remain only where they make the dish:
- halal lap cheong
- ikan bilis
- peanuts
- garlic chives
- Padang spice set
- certified processed sauces/condiments
